Illustrated example · sample data
  1. Open Barcode Printing → Print Jobs. A print job is a saved batch of barcode labels that you can load and print together.
  2. Choose a saved job by its name and label count, then click Load Print Job. Selecting a different job does not load it automatically: click Load Print Job each time.
  3. Check Total Labels, Different Barcodes and the barcode list. Repeated barcodes are multiple labels for the same code; this example has six labels for two different codes.
  4. Click Print Loaded Labels. In the browser print dialog, select your label printer and the matching 2×1-inch stock (the page uses 51 × 25 mm). Check the preview, use 100% scale and turn off headers and footers if shown, then print.
  5. Clear Loaded Labels clears the current batch and preview; it does not delete the saved job. Loading and printing it again produces another copy of the batch.
  6. Finished with a job? Select it, click Delete Print Job and confirm its name. This permanently deletes the saved job and its labels; products and stock quantities stay unchanged.
Create and fill a job: open Add Stock → Printing Options, enter a New Print Job Name and click Create New Print Job, or choose an existing Print Job. Tick “Create barcode labels for these items”, then enter the product, quantity and location and click Save Product. The saved barcode is added to that job with one label per unit. Auto print is separate: leaving it enabled also prints immediately. Return to Barcode Printing → Print Jobs to load and print the saved batch.
No jobs listed? Check that the correct inventory is selected, then reopen Barcode Printing. If stock saves but labels cannot be confirmed, do not add the stock again: check the job’s counts and print any missing labels separately. Find it: Operations → Barcode Printing → Print Jobs. For printer setup, open Printer Setup. This batch-print button uses browser printing; it does not use Add Stock’s QZ auto-print option.
3

Other barcode printing options

Choose the tab that matches the labels you need.

Product Labels: type into Live Product Search, find the matching item and select Print Product Label.

Location labels: open the location-label tab (for example, Box Labels or Shelf Labels), select the saved location and use its print button.

Bulk Range: enter a prefix, Start Number and End Number, then select Generate Range Labels. For example, ITEM- with 33 to 35 creates ITEM-33, ITEM-34 and ITEM-35. Check the generated labels, then select Print Generated Labels. Both end numbers are included; the limit is 300 labels per range.

Quick Print: enter an existing barcode and select Print Barcode to print one label.

Before switching between Bulk Range and Print Jobs: clear the loaded labels, then generate or load the batch you want. These tabs share the currently loaded print batch.

Labels only: printing or generating barcode labels does not create products or add stock. Record the items through Add Stock separately.

Find it: Operations → Barcode Printing → the relevant tab.
