INVENTORYOS RETAIL — HELP CONNECTION (v15)

Follow RETAIL-HELP.txt. This connects the new Retail Help button to your existing
Help records, admin portal and notification email. No Stripe setup is needed.

Extract the whole InventoryOS-retail-help-update folder into your backend
folder, next to server.js. Finish open baskets, sync offline sales and stop the
backend. In PowerShell opened in the backend folder, run:

  node .\InventoryOS-retail-help-update\install.cjs
  node .\check-retail.cjs
  node .\check-retail-help.cjs

If both checks pass, restart the backend, then refresh/reopen Retail.

Your existing Help backend must already be installed. This update does not
replace utils/helpRequests.js, its SQL or your original Help/admin routes.
It uses the same account email, rate limits, history and notification worker.
It also includes all previous Retail receipt, billing and shop updates.

The website/frontend update is deployed separately from this backend ZIP.
Your .env and protected admin middleware are retained. Code backups are made.
