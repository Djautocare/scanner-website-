INVENTORYOS RETAIL — STORE DELETION (v17)

This fixes the account email stuck on Loading and the locked deletion controls.
The database catalog now uses the array format supported by node-postgres.
The check command also tests the real deletion preview for every existing shop.

Read STORE-DELETION.txt for the full instructions.

Extract InventoryOS-retail-store-deletion-update into the backend folder beside
server.js. Finish transactions, sync offline sales and stop the backend. Run:

  node .\InventoryOS-retail-store-deletion-update\install.cjs
  node .\check-retail.cjs
  node .\check-retail-store-deletion.cjs

If both checks pass, restart the backend and refresh/reopen Retail.
No new .env settings, Stripe products or npm packages are needed.

Admin > Stores & billing > Delete store emails your CSV backup first. The owner
must confirm it has been received and saved and type Confirm delete exactly.
This includes all prior Retail updates, with code backups and safe retry checks.
