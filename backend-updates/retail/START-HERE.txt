INVENTORYOS RETAIL — RECEIPT UPDATE (v14)

Existing Retail installation: follow RECEIPT-LAYOUT.txt.

This update changes printed/email receipt shop names, cashier numbers and email
appearance. You do NOT need to rerun Stripe setup or change prices or keys.

Extract the whole InventoryOS-receipt-layout-update folder into your backend
folder, next to server.js. Finish open baskets, sync offline sales and stop the
backend. In PowerShell opened in the backend folder, run:

  node .\InventoryOS-receipt-layout-update\install.cjs
  node .\check-retail.cjs

If the check passes, restart the backend, then refresh/reopen Retail and Till.

The website/frontend update is deployed separately from this backend ZIP.
The ZIP does not replace your server.js wholesale, .env, database or non-Retail
features. It preserves protected admin middleware and backs up replaced files.

For a first-time installation only, the included STRIPE-SETUP.txt and
EMAIL-RECEIPTS.txt explain the separate subscription setup. Existing configured
installations should not repeat those steps for this receipt update.
